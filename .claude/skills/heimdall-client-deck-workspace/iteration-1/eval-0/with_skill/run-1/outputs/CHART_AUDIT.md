## Global decisions carried from Ragnar (apply unchanged unless the data argues)

1. y is the segment correlation itself, never "lift vs Average Person" — the 20-generic-row
   control is a popularity axis (creatine seg +0.000 / "lift" −0.315). The average is a band =
   the middle half of all charted entities, as TAB drew it.
2. Unvolumed rows: drop when the value is an outlier for the category; keep when plausible
   (Tesla Model Y, Oura). Say which in this file.
3. Volume 0 with h≈0 on a famous name = placeholder, not a measurement — drop by name.
4. Every substitution lives in `client_config.json::substitutes`; every exclusion in
   `exclude.json` by name, with the reason in this file.
5. Where the entity read contradicts an anchor-level or prior-deck finding, state the
   correction on the slide (Ragnar: the 15-passenger van; lodging is Hyatt not Super 8). For
   Vacation Races the candidates are: (a) lodging tier, (b) whether the car matters at all for a
   fly-in audience, (c) whether `yellowstone`/`grand canyon` bare rows under-index because of
   their collisions.
6. A category with fewer than ~15 trustworthy entities is merged or dropped, never padded.
7. Entities not in the corpus are queued for onboarding by the engine automatically; list them
   here per category and re-run `deck_data.py` on the next cycle to thicken Competitors first.
